# Mafia Overlay Helper (Android)

Минимальный исходный проект Android Studio: плавающее окно + OCR видимого текста экрана.

## Что умеет
- Запрашивает системное разрешение на отображение поверх других приложений.
- Показывает плавающую панель с кнопкой «Скрыть».
- По отдельному согласию Android захватывает экран и распознаёт видимый текст через ML Kit.
- Выводит распознанные строки в панели.

## Чего не делает
- Не читает память игры, сетевой трафик или закрытые данные сервера.
- Не определяет скрытые роли и не гарантирует распознавание ников.
- Не нажимает кнопки и не управляет игрой.

## Сборка
1. Открой папку проекта в Android Studio (Giraffe или новее).
2. Дождись синхронизации Gradle.
3. Собери APK через **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Установи APK на свой Android.
5. Выдай разрешение «Поверх других приложений».
6. Нажми «Запустить плавающее меню».
7. Для OCR нажми «Начать распознавание» и подтверди системный запрос захвата экрана.

На Android 13+ может понадобиться разрешить уведомления. Системный индикатор захвата экрана будет виден, пока OCR работает.

## Примечание
Это стартовый прототип. На разных версиях Android производители могут ограничивать фоновые сервисы и захват экрана. Проверяй распознавание на обычном тексте интерфейса; для анализа голосований потребуется отдельная логика поверх распознанных строк.
